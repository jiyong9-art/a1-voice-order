# A1 음성 (a1-voice-float)

카톡·문자·네이트온 어디서든 **화면 위 A1 글자**를 두 번 톡톡 누르면 녹음이 시작되고,
말이 끝나면 `a1-voice-order` 의 Whisper(`gpt-4o-transcribe`)로 변환해 **입력칸에 바로 넣어주는**(또는 자동 복사하는) 안드로이드 앱.
말하는 동안에는 폰 음성인식의 **실시간 자막**이 작게 떠서 말한 내용을 바로 볼 수 있다.
**길게 꾹** 누르면 플로팅이 꺼진다(5번 연타 대신). 녹음 파일(`.m4a`)로 저장하는 일은 알림·결과 창의 `[녹음]` 버튼이 맡는다.

- 패키지: `kr.inu.a1voice` · 이름: `A1 음성` · **versionName 1.8 (versionCode 9 · 2026-11-22 반투명 둥근 배지·상태 점·길게 꾹=끄기·무음 환각 제거·긴 자막·위치 고정)**
- 배포본 보관: v1.8 — `archive/a1-voice-float-v1.8.apk` · 이전 버전: v1.7(versionCode 8, 배포본은 v1.8 로 대체됨·소스는 Git 이력에 있음), v1.6(versionCode 7) — `archive/a1-voice-float-v1.6.apk`, v1.5(versionCode 6) — `archive/a1-voice-float-v1.5.apk`, v1.4(versionCode 5) — `archive/a1-voice-float-v1.4.apk`, v1.3(versionCode 4) — `archive/a1-voice-float-v1.3.apk`, v1.2(versionCode 3) — `archive/a1-voice-float-v1.2.apk`, v1.0 — `archive/a1-voice-float-v1.0.apk`
- minSdk 26 (Android 8) / targetSdk 34
- 외부 라이브러리 0개 (Android 프레임워크만 사용) → APK 약 192KB (196,771 bytes, v1.8)
- 배포: `https://a1kr.com/app/a1-voice.apk`

## 기능

| 동작 | 설명 |
|---|---|
| **플로팅 = 반투명 둥근 배지 + 상태 점 (v1.8)** | `SYSTEM_ALERT_WINDOW` 오버레이. **반투명 둥근 배지**(다크네이비 80%·1dp 흰 테두리) 위에 흰 `A1`, 오른쪽 위 **상태 점**(초록=켜짐/대기, 하늘색=말하는 중, 노랑=변환 중). 크기 58dp, 드래그로 이동·좌우 테두리에 붙음, 앱 설정에서 **위치 고정** 가능 |
| **최소 크기 유지 (v1.8)** | 어떤 상태에서도 배지가 0.94배 아래로 작아지지 않는다. 말하는 중에는 1.04배로 살짝 커지고 하늘 테두리가 돌 뿐, 녹음·변환·이동 중에도 크기가 그대로라 손가락으로 잡기 쉽다 |
| **말하는 동안 실시간 자막 (v1.7)** | 두 번 톡톡으로 말하기 시작하면 플로팅 바로 위에 **작고 얇은 반투명 말풍선**이 떠서, 폰 음성인식(`SpeechRecognizer`, ko-KR)의 부분 결과를 옅게 갱신한다. 한 번 톡 누르면 창이 닫히고 **OpenAI 정확한 글자**로 바뀌어 입력칸에 들어간다. Android 13+ 에서만 동작하고, 미지원이면 자막만 조용히 생략된다 |
| **홈 화면 1×1 위젯 (v1.8)** | 반투명 둥근 배지 + `A1`. **점 초록=켜짐, 회색=꺼짐.** 한 번 탭 = 앱 설정 화면 없이 플로팅 즉시 켜기/끄기 + 토스트(`A1 플로팅 켜짐` / `A1 플로팅 꺼짐`). 로그인·`다른 앱 위에 표시`·마이크가 빠져 있으면 앱 설정 화면을 열어 안내 |
| **상단 빠른 설정 타일 (v1.6)** | 상단바를 내려 `A1 음성` 타일을 누르면 위젯과 똑같이 즉시 토글. 타일 상태(`STATE_ACTIVE`/`STATE_INACTIVE`)·부제(`켜짐`/`꺼짐`)가 서비스 상태와 동기화 |
| **녹음 파일 저장 = [녹음] 버튼 (v1.8)** | **알림의 `[녹음]`** 또는 결과 창의 `[녹음]` 을 누르면 조용히 녹음 파일 저장이 시작된다(상태 알약 `● 녹음 저장 중`). 다시 A1을 한 번 톡 누르면 `Recordings/A1녹음/A1_YYYYMMDD_HHMMSS.m4a` 로 저장 → 토스트 `녹음 저장됨`. 최대 60분 |

| **무음이면 보내지 않음 (v1.8)** | 말소리가 없으면(SilenceGate: 최고 음량·RMS·말소리 조각) 서버로 올리지 않고 `말소리가 없어요` 로 끝낸다 — 엉뚱한 문장(환각)이 나오지 않는다 |

### 접근성(입력칸 바로 넣기) 켜는 법

1. 앱 첫 화면 → 준비 상태의 **`입력칸 바로 넣기 (접근성)`** → **[설정 열기]**
2. 목록에서 **`A1 음성 입력칸 넣기`** 를 찾아 켜기 (삼성: 설정 → 접근성 → 설치된 앱)
3. 안드로이드 13 이상에서 "제한된 설정" 경고가 뜨면: 설정 → 앱 → A1 음성 → 오른쪽 위 ⋮ → **제한된 설정 허용** 후 다시 켜기

켜지 않아도 앱은 그대로 동작한다(자동 복사 + 결과 창). 켜면 한 단계가 줄어든다.

## 빌드 (Gradle 없이)

```sh
KS_PASS='<서명키 비밀번호>' sh build.sh   # aapt2 → javac → d8 → zipalign → apksigner
# 결과: build/a1-voice-float.apk
```

필요한 것: JDK 17(`/workspace/tools/jdk`), Android SDK 빌드툴 34 + platform 34(`/workspace/tools/sdk`).
서명 키는 `keystore/a1voice.jks` 이며 **저장소에 넣지 않는다**(비밀번호는 `KS_PASS` 환경변수로만 받는다).
**이 키를 잃으면 같은 앱으로 업데이트 설치가 안 된다** — 보관할 것.
배포는 `servers/a1-total-seoul/apk-put.py <apk>` → `/var/www/a1-dl/a1-voice.apk`.

## 음성 파일 변환 · 기기 저장 · 업데이트 (v1.3 → v1.4)

### 1) 파일/폴더 열어 변환 (`FileTranscribeActivity`)
- 첫 화면 `플로팅 켜기` 아래 **`음성 파일 변환 (녹음 열기)`** → `[녹음 파일 열기]` 또는 `[폴더 열기]`
- 파일 선택은 SAF(`ACTION_OPEN_DOCUMENT`), 폴더는 `ACTION_OPEN_DOCUMENT_TREE` 후 `DocumentsContract` 로 폴더 안 음성 파일 목록을 만든다(외부 라이브러리 없이).
- 지원: `.m4a .mp3 .wav .ogg .aac .flac .amr`(+`.mp4 .3gp .m4b .opus .wma` 시도)
- **20MB 이하이고 15분 이하**면 원본을 그대로 `/api/transcribe` 로 보낸다(확장자를 유지해 임시 사본을 만든 뒤 업로드).

### 2) 15분 단위 분할 (`AudioChunker`)
15분 초과 또는 20MB 초과면 두 길로 나눈다.

**① 빠른 길 (v1.4, 무손실)** — m4a·aac·mp4·3gp 처럼 MP4 컨테이너에 그대로 담을 수 있는(AAC·AMR) 트랙은
`MediaExtractor` 로 샘플을 읽어 `MediaMuxer` 에 **그대로 복사**한다. 소리를 풀었다가 다시 압축하지 않으므로
**1시간 녹음도 1~2초대**이고 음질도 원본 그대로다. 조각 경계는 **15분 또는 18MB 중 먼저 닿는 쪽**
(서버 한도 24MB 아래로 넉넉히).

**② 다시 담는 길 (v1.3부터, 폴백)** — mp3·wav·ogg·flac·amr 처럼 MP4 로 그냥 담을 수 없는 형식은
`MediaCodec` 디코더(PCM) → 모노 다운믹스 + 선형보간 16kHz → `MediaCodec` AAC 인코더 → `MediaMuxer` 로
`part_01.m4a`, `part_02.m4a` … 15분 조각(64kbps → 15분 약 7MB)을 만든다.

자동 폴백 조건: 코덱·컨테이너가 복사를 거부하거나, 조각이 22MB를 넘거나, 끝까지 읽지 못하고 앞부분만 복사된 경우.
그 밖의 기존 안전장치도 그대로다 — 20MB 이하·15분 이하면 나누지 않고 한 번에 전송, 분할이 통째로 실패하면 24MB 이하일 때만 원본으로 1회 시도.
조각은 순서대로 변환한 뒤 `\n` 으로 이어 하나의 글로 만들고, 진행률은 `i/n 구간 변환 중…`, 나누는 동안은 `15분 단위로 나누는 중… 42%`.

> 조각 경계 규칙은 `test/BoundaryTest.java` 로 JVM에서 검증한다(14:59.9/15:00.0, 18MB 상한, 1시간=4조각, 320kbps 1시간=9조각·최대 17MB).

### 2-1) 실시간 글자 표시 · 부분 저장 (v1.4)
- 결과 상자는 변환이 시작될 때부터 열려 있고, 제목이 `변환 중… (1/3)` 처럼 바뀐다.
- 조각 하나가 `/api/transcribe` 응답을 받으면 곧바로 본문에 이어 붙는다(`showLive`). 진행 중 본문은 옅은 글씨 `#64748B`, 배지 `저장 중… (1/3 구간 완료)`.
- 전부 끝나면 제목 `변환 결과`, 본문은 진한 글씨 `#0F172A` 로 확정되고 그때 기기 기록에 저장된다.
- 중간에 네트워크 오류·취소로 끊기면 그때까지의 글을 `파일명 [부분 저장]` 으로 `filesDir/transcripts.json` 에 남기고 화면에도 옅은 글씨로 보여 준다(`partialSaveOrError`).

### 3) 기기 저장 기록 (`History` · `HistoryActivity`)
- 저장 위치: **앱 전용 `filesDir/transcripts.json`** (JSON 배열, 최근 300건). 서버·클라우드로 전송하지 않는다.
- 항목: 제목(파일명) · 구분(파일/플로팅) · 시각 · 길이 · 구간 수 · 글 전체
- 첫 화면 `기록 보기` → 목록(제목·시각·길이·글자수·미리보기) → 열어서 확인/복사/삭제, 상단 `전체 삭제`
- 플로팅으로 말해 변환한 글도 같은 기록에 `플로팅` 으로 쌓인다.
- 앱을 지우면 기록도 같이 사라진다(백업·복원 없음 — "남의 것까지 듣고 싶지 않다" 지시에 맞춘 기기 전용).

### 4) 자동 업데이트 안내 (`UpdateChecker`)
- `https://a1kr.com/app/version.json` 을 앱을 열 때 백그라운드로 확인(3시간에 한 번, 실패는 조용히 무시).
- 서버 `versionCode` > 깔린 `versionCode` 면 **`New version v1.4 available`** + `[Update]` / `[Later]`.
- `[Update]` → 제목이 **`Updating...`** 으로 바뀌고 진행 막대와 함께 `version.json` 의 `url`(기본 `https://a1kr.com/app/a1-voice.apk`)을 브라우저로 연다. 사용자는 브라우저에서 받아 "설치"만 누르면 된다(같은 서명키라 덮어쓰기 업데이트).
- 첫 화면 맨 아래 `A1 음성 v1.4 · 새 버전 확인` 을 누르면 즉시 확인하고, 최신이면 `Latest version v1.4` 토스트.

```
GET https://a1kr.com/app/version.json
{"versionCode":9,"versionName":"1.8","url":"https://a1kr.com/app/a1-voice.apk"}
```

## 서버 계약 (a1-voice-order)

```
POST {server}/api/auth/login      {"name":"<이름>","passcode":"<팀 비밀번호>"}
  → 200 {"ok":true,"name":"문지용"} + Set-Cookie: inu_session=...
  → 401 {"ok":false,"error":"팀 비밀번호가 맞지 않습니다."}

POST {server}/api/transcribe      multipart/form-data, field "audio" (파일)
  Cookie: inu_session=...
  → 200 {"ok":true,"text":"...","model":"gpt-4o-transcribe"}
  → 401 로그인 필요 / 422 인식 실패 / 429 요청 과다
```

`/api/transcribe` 는 개인정보 가림(masking)을 하지 않아 붙여넣기용 원문이 그대로 온다.
(서버에 그 경로가 없으면 `/api/sales/voice` + `x-a1-passcode` 로 대신 시도하고 `transcript` 만 사용)

### 3) 제스처: 두 번 톡 = 말하기 · 길게 꾹 = 끄기
| 동작 | v1.7 | **v1.8** |
|---|---|---|
| 두 번 톡톡 | 글자 변환 시작/종료 | 그대로 |
| 한 번 탭 | 녹음 중이면 종료 · 아니면 안내 | 그대로 |
| 길게 꾹(0.45초) | 녹음 파일 저장 | **플로팅 끄기**(진행 중 녹음은 보내지 않고 폐기) |

### 4) 무음일 때의 빈칸 환각 제거 (앱 + 서버)
- **앱**: `SilenceGate` 가 16kHz 모노 16비트 PCM 을 0.1초 조각으로 재서 RMS·최고 음량·말소리 조각 수를 센다.

  `말소리가 없어요. 다시 말씀해 주세요.` 로 끝낸다(비용·지연 0). 규칙은 `test/SilenceGateTest.java` 로 JVM 검증.
- **서버(`a1-voice-order`)**: `lib/audio-guard.ts` 가 WAV 를 직접 재서(길이·RMS·말소리 구간) 같은 판단을 하고,
  무음·0.35초 미만이면 모델을 부르지 않고 `{ok:true,text:"",silent:true,reason:"silent|too_short"}` 를 돌려준다.
  힌트 프롬프트도 문장형에서 **짧은 고유명사 목록**으로 바꾸고, 결과가 힌트를 그대로 읽은 문장이면
  (`looksLikePromptEcho` — `에이원코리아입니다`, `유병헌 과장님` 등) `reason:"prompt_echo"` 로 비운다.
- 앱은 `silent:true` 를 오류가 아니라 '말소리 없음'으로 받아 조용한 토스트만 띄운다(오류 창 없음).

### 5) 실시간 자막이 길게 말해도 계속 보이게
- `LiveCaption`: 자막 세션 재개 횟수 제한(30회 → 없음)을 없애고 **연속 실패 8회**일 때만 포기한다.
  문장이 확정되면 줄을 바꿔 쌓고(`\n`), 10초간 아무 소식이 없으면 watchdog 이 세션을 새로 연다.
- 자막 창은 **5줄**까지 늘어나고(300dp), `OverlayService` 가 최근 **240자**만 남겨(`tail()`) 앞을 `…` 로 접는다 —
  최근 말이 항상 보이고 오래된 말이 위로 밀려 사라진다.

### 1) 플로팅 버튼 = `A1` 로고
- 대기: 다크네이비 원 + 가운데 **흰색 `A1`** (21sp bold, 자간 0.02). 마이크 아이콘은 쓰지 않는다.

### 2) 길게 꾹(0.55초) = 녹음 파일 저장
- `GestureDetector` 와 별개로 `ACTION_DOWN` 에서 0.55초 타이머를 걸고, **터치 이동이 `touchSlop`(10dp)을 넘거나 드래그로 판정되면 타이머를 취소**한다(위치 이동과 녹음이 겹치지 않게). `GestureDetector` 자체의 롱프레스도 단일 탭을 막아 주므로, 손을 떼도 바로 종료되지 않는다.
- 녹음 중 한 번 톡 → 저장. 저장 위치는 **기기 공용 `Recordings/A1녹음/A1_YYYYMMDD_HHMMSS.m4a`**.
  - Android 10+ : `MediaStore.Audio.Media` 에 `RELATIVE_PATH = Environment.DIRECTORY_RECORDINGS + "/A1녹음"`, `IS_PENDING` 1→0. **저장소 권한 불필요**, 파일 앱·[폴더 열기]에서 바로 보인다.
  - Android 9 이하: `Environment.getExternalStoragePublicDirectory(DIRECTORY_RECORDINGS)/A1녹음` 에 직접 쓰고 `MediaScannerConnection.scanFile` 로 목록 갱신(이 경로만 `WRITE_EXTERNAL_STORAGE` `maxSdkVersion=28` 필요 — 첫 화면에서 자동 요청).
  - 둘 다 실패하면 앱 외부 폴더(`getExternalFilesDir(DIRECTORY_MUSIC)/A1녹음`)로 폴백한다.
- 파일 형식은 AAC 44.1kHz 모노 96kbps(나중에 다시 듣기 좋게, 1시간 ≈ 43MB). **최대 60분**에서 자동 저장 종료.
- 임시 파일은 캐시에 만들고 저장이 끝나면 지운다. 1시간이 지난 임시 파일만 시작할 때 정리한다.

### 3) 4연타(1.1초 안에 4번) = 플로팅 끄기
- `ACTION_DOWN` 마다 `TapRing`(최근 4탭 시각)에 기록하고, 첫 탭~4번째 탭이 1.1초 이내면 **제스처 해석보다 먼저** 종료한다.
- 두 번째 탭에서는 기존처럼 **지연 없이** 글자 변환이 시작되고, 3·4번째 탭이 이어지면 그 녹음을 **서버로 보내지 않고 폐기**(임시 파일 삭제)한 뒤 토스트 `플로팅 종료됨` + `stopSelf()`.
- 변환 요청이 이미 나갔더라도 `sessionGen` 이 달라지면 결과를 버리고 저장하지 않는다.
- 롱프레스·드래그 뒤에는 탭 기록을 비워 오발동을 막는다. 판정 규칙은 `test/TapRingTest.java` 로 JVM에서 검증한다.

### 4) 체감 반응 속도
- 두 번 톡톡·길게 꾹이 감지되면 `MediaRecorder.prepare()/start()` **전에** 모양 변경과 15ms 진동을 먼저 실행한다. 마이크가 열리지 못하면 모양을 원래대로 되돌리고 안내 창을 띄운다.

### 5) 그대로 유지되는 것
v1.4 의 고속 무손실 분할(`AudioChunker`), 실시간 글자 표시, `[부분 저장]`, 기기 로컬 기록, 접근성 바로 넣기, 로그인 잠금, `UpdateChecker`(`version.json`) 전부 그대로다.

## 알려진 사항

- 무음/잡음만 녹음하면 Whisper 가 엉뚱한 문장을 만들 수 있다(모델 특성). 0.7초 미만 녹음은 아예 보내지 않는다.
- 재부팅하면 버블은 사라진다. 앱 아이콘을 눌러 다시 켜면 된다(로그인·권한이 있으면 자동으로 뜬다).
- 팀 비밀번호 기본값은 넣지 않는다 — 처음 한 번 직접 입력하면 그 기기에만 저장된다. (v1.0은 팀 비밀번호가 기본값으로 들어 있어 배포용으로 부적합 → `archive/a1-voice-float-v1.0.apk`에만 남겨 둠)
- 이름 칸도 v1.2부터 빈칸이 기본이다. 저장된 값이 있을 때만 채워진다.
- 로그인 게이트는 "이 기기에서 서버 로그인이 확인됐는가"를 본다. 쿠키가 만료돼 `/api/transcribe` 가 401을 주면 앱이 저장된 비밀번호로 자동 재로그인한다.
- 접근성 서비스는 입력칸을 찾아 글자를 넣는 데만 쓴다. 화면의 다른 글자를 읽거나 저장·전송하지 않는다(이벤트도 포커스/창 전환만 받는다).
- 파일 변환은 안드로이드 기본 디코더가 지원하는 형식만 된다(v1.4는 AAC/AMR 원본 복사, 그 외 재인코딩).
- 빠른 길(v1.4)은 **원본 비트레이트 그대로** 올린다. 1시간 128kbps 녹음이면 약 58MB(재인코딩은 약 28MB)라 분할은 빨라지지만 **데이터 사용량은 늘어난다**. 데이터를 아껴야 할 때는 Wi-Fi에서 열 것. 디코더가 없는 형식(일부 DRM·특이 코덱)은 "이 형식의 소리를 풀지 못했습니다" 로 안내한다.
- 서버 `/api/transcribe` 는 Vercel 함수라 **요청당 120초** 제한, **시간당 40회** 제한이 있다. 아주 긴 녹음은 15분 조각 수만큼 요청이 나가므로, 2시간 넘는 파일은 10조각(요청 10회) 이상이 될 수 있다.
- 변환 기록은 기기에만 있어서 앱 삭제·기기 변경 시 옮겨지지 않는다. 필요하면 결과 화면에서 `전체 복사` 로 밖에 빼 둘 것.
- **길게 꾹 저장한 녹음 파일(v1.5)은 서버로 보내지 않는다.** 기록(`transcripts.json`)에도 넣지 않으므로 글자 변환 비용·전송이 전혀 없다. 기기 파일 앱의 `Recordings/A1녹음` 에만 남는다(앱을 지워도 파일은 남는다).
- 녹음 파일 저장 중에는 화면에 타이머를 띄우지 않는다(티 안 나게). 녹음 중인지 확인하려면 글자가 작아지고 검은 점이 보이는지 보면 된다.
- **실시간 자막(v1.7)은 Android 13(API 33) 이상에서, 폰 음성인식이 `EXTRA_AUDIO_SOURCE`(파이프로 넘긴 소리)를 지원할 때만 뜬다.** 미지원 기기(일부 삼성 음성인식 등)에서는 자막 창이 잠깐 떴다가 사라지고, 녹음·Whisper 변환은 그대로 동작한다.
- v1.7부터 두 번 톡톡 녹음은 `.m4a`(AAC) 대신 **`.wav`(PCM 16kHz 모노)** 로 만들어 올린다. 음질 손실이 없고 2분 녹음이 약 3.8MB(서버 한도 24MB)다. 길게 꾹 저장하는 녹음 파일은 예전처럼 `.m4a`(44.1kHz·96kbps)다.
- v1.8부터 끄기는 **길게 꾹**(0.45초)이다. 녹음 중에 길게 누르면 그 녹음은 저장·전송되지 않고 버려진다. 실수로 껐으면 앱을 열어 `플로팅 켜기` 를 누르면 된다.
- 배지가 손에 자주 걸리면 앱 첫 화면 `플로팅 위치 고정` 을 켜 두면 끌어도 움직이지 않는다.
- 무음·아주 짧은 녹음은 서버로 가지 않는다(앱 `SilenceGate` + 서버 `lib/audio-guard.ts`). 그래도 아주 조용한 잡음만 있는 녹음은 `말소리가 없어요` 로 끝난다.
- Android 9 이하에서 저장이 앱 폴더로 폴백되면 첫 화면의 안내대로 저장소 권한을 허용해 주면 공용 `Recordings/A1녹음` 에 저장된다.
